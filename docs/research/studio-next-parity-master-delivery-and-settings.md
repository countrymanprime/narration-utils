**Date:** 2026-10-12. **Code audited:** `main` at `4c9b980`, after the Settings, Master & QC and Delivery swap (SN-M5, #1585, `a46472c`). **Slice:** SN-C36 (#1212), SNC-3 of the [Studio Next cutover PRD](../prds/studio-next-cutover.prd.md). **Mock audited:** `docs/research/mockups/studio-next/tests/`. **Page PRD:** [studio-next-master-delivery-and-settings.prd.md](../prds/studio-next-master-delivery-and-settings.prd.md). SN-C4 reads this note when it flips the ratchets; SN-C51 and SN-C52 read it for the steady-state docs.

Method: each mock case is a row below, mapped to a real test by name. The real test, or the page code where the row's note says it asserts less, was read. The checker is `node scripts/ci/studio-next-parity.mjs`. It proves a cited test file exists and holds the name; it does not prove the test asserts what the mock case asserts. The app was not run and the Playwright suites were not run. The cited real tests were run once (see [Verification](#verification)). The seven files hold 119 cases by the checker's count (13, 13, 9, 14, 13, 49 and 8); the slice text says 116.

## Result

**Update 2026-10-17.** The mock's Settings page was redesigned ([ADR 0865](../adr/0865-settings-are-grouped-by-what-is-configured-with-a-scope-and-a-used-by-list-on-every-setting-and-a-model-list-that-owns-the-downloads.md), Proposed). `settings.test.tsx` kept the cases below that still hold and gained 37, listed as `mock-only` with a pointer to the ADR. The counts that follow are for 2026-10-12 and were not recounted.

- 119 mock cases: 60 `ported`, 39 `covered`, 20 `mock-only`. Of the 20, 11 are gaps (rows whose note starts `GAP`), 8 are the mock's Companion page (DQ-13) and 1 is the mock's undo model (a scan is one undo step). 22 `covered` rows name a gap in their note. So 33 rows are open and 86 are not.
- 23 gaps (G1 to G23), under [Gaps](#gaps).
- **Four Settings panels of the mock have no page and no slice:** Recording (G11), Definitions (G12), Reader text (G13) and Marks (G14). `SettingsPage.tsx` and the page PRD's status line say they wait on a host model.
- **The real Replace manuscript resets; the mock's flags.** The real one clears the Story Bible, notes, bookmarks, statuses and comparison results behind "Replace and reset". The mock keeps the work and flags changed chapters (G18, G19). This needs an owner ruling before a slice.
- **GLiNER and BookNLP are built but not wired into the host scan** (G22): an installed tool would read "not available yet". No production analysis tool is downloadable yet (every catalog row waits on the owner's pins).
- **Master & QC is file-based, Delivery is chapter-based.** Master's rows are measured files named by file name; most of G1, G2 and G6 follow from that.
- Rulings: CO-1 (`deferred`) and CF-12 (`agreed`, text "Companion: deferred"). Neither has a test row; see [Rulings](#rulings).
- Old equivalents: 21 checks. 10 leftovers (L1 to L10 under [Leftovers](#leftovers)): stale doc images, generated atlas pages, comments, a visual row, three guide or PRD lines and the unexplained "Experimental REAPER actions" switch.
- No product test was added: the slice owns one file.

**The checker has no status for a gap.** A mock case with no real test must still have a row, and only `mock-only` passes with an empty `real test`. Gap rows therefore carry `mock-only` and a note that starts `GAP Gn`, as the other parity notes do. They are not excused: each has an entry under [Gaps](#gaps). SN-C4 should count them as open. A `covered` row whose note starts `GAP Gn` has a real test that asserts less than the mock case, or tests a seam the page does not mount; it is open too.
